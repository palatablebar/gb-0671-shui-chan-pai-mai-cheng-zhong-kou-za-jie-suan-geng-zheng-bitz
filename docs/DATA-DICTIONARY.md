# 数据定义

票号与原始编号均为字符串，保留前导零。称重支持 kg、公斤与 t，统一为 kg，单价为 CNY/kg。
毛重与皮重按票号和版本配对，品类、单价、扣杂率与更正目标必须一致。计价重量=(毛重−皮重)×(1−扣杂率)，先量化到0.001kg，再乘单价，金额四舍五入到0.01CNY。
收市补秤单只带新毛重（版本≥2、填写替代版本、同组无皮重行）。补秤只能沿用同票被替代版本的原皮重与成交依据：缺少对应原票（REWEIGH_NO_ORIGINAL）、品类不一致（REWEIGH_FISH_MISMATCH）、单价或扣杂率与原票冲突（REWEIGH_DEAL_MISMATCH）、沿用后净重为负（REWEIGH_NEGATIVE_NET）一律隔离，不进入可付款结果，原票旧版结果与原始称重证据保留。补秤单的单价、扣杂率、已付留空即继承原票，显式填写则必须与原票一致。
同票同版本补秤同值重复到达只计一次（重复数计入 reweigh_duplicate）；同票同版本出现不同新毛重，全部按 REWEIGH_DUPLICATE 隔离。补秤结果记录补秤前毛重 base_gross_kg、毛重差额 gross_delta_kg、补秤前应付 amount_before、应付差额 amount_delta、皮重依据 tare_source 与成交依据行 base_lines，支持按版本链连续补秤。
每票第一版不填写 replaces。后续版本只能替代当前生效版，分支或缺基版整票阻断结算。已支付额为各版本中最大累计已付值，待付=最终应付−累计已付；负待付表示待收回。
同编号同原值仅计一次；同编号不同原值全部隔离。空文件、全空行和仅表头分别报错。原始输入计数包括空行及重复表头，对账会分别解释。
对账行守恒：输入行=常规采纳+隔离+空行+同值重复行+重复表头+补秤采纳(reweigh_adopted)+同值补秤重复(reweigh_duplicate)。阻断计数 blocked 包含版本冲突与全部 REWEIGH 原因码。
归档封存保存逐版证据、隔离原因和运行摘要，非支付执行系统。数据使用虚构编号，不连接实际支付渠道。
